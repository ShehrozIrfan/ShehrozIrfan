# Shehroz Irfan

### Senior Full-Stack Engineer · Toptal Top 3% · Remote worldwide

**Portfolio and case studies: [shehrozirfan.dev](https://shehrozirfan.dev)**

I build production SaaS with TypeScript, Node.js, React, Next.js and PostgreSQL on AWS. Most of my professional work is in private repositories, so this profile shows my stack and a few learning projects rather than my employer's code. The case studies on [shehrozirfan.dev](https://shehrozirfan.dev) cover the real work.

## What I've worked on

- **COBUL:** an LLM-powered home-repair diagnosis platform, built solo, end to end.
- **Gharhub:** led 4 junior developers and 1 QA to deliver a B2B/B2C marketplace MVP and internal CRM, including a double-entry ledger.
- **Skillko:** SCORM 1.2/2004 integration, Photo Audit and transactional partner onboarding.
- **Video background-removal API:** built and deployed on AWS, solo (Lambda, ECS Fargate, Python worker).

Cursor and Claude Code are part of my daily workflow, and I review AI-generated code for correctness, security and maintainability before it ships.
